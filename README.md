# ÖBA Oto

ÖBA eğitim videolarında video bitince "Sonraki / İleri / Devam" düğmesine kendisi basar.
Soru gelince durur, cevap verilene kadar sesli uyarı verir ve telefonu titretir.

Kurulum sayfası: https://karadenizmehmet-debug.github.io/Oba-oto/

- `index.html`: kurulum sayfası (telefon ve bilgisayar adımları, uyarı testi)
- `oba-oto.user.js`: Tampermonkey betiği (otomatik güncellenir)

Videoyu hızlandırmaz, atlamaz, soruları cevaplamaz.
